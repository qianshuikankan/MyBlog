
# 字符流

## 1.父类

### 1. **`Reader`**（抽象类）

- **描述**：抽象类，是所有字符输入流的父类。
- **重要构造函数**：无直接构造函数，因为它是一个抽象类。
- **重要方法**：
    - `int read()`：从输入流中读取单个字符，返回读取的字符（`int` 类型），到达流末尾返回 `-1`。
    - `int read(char[] cbuf)`：从输入流中读取字符到指定的字符数组，返回实际读取的字符数，到达流末尾返回 `-1`。
    - `int read(char[] cbuf, int off, int len)`：从输入流中读取字符到指定的字符数组的指定范围，返回实际读取的字符数，到达流末尾返回 `-1`。
    - `void close()`：关闭输入流并释放与之关联的系统资源，可能抛出 `IOException`。


### 2. **`Writer`**（抽象类）
- **描述**：抽象类，是所有字符输出流的父类。
- **重要构造函数**：无直接构造函数，因为它是一个抽象类。
- **重要方法**：
  - `void write(char[] cbuf)`：将字符数组写入输出流。
  - `void write(String str)`：将字符串写入输出流。
  - `void close()`：关闭流并释放系统资源。

在 Java 中，字节流和字符流是 I/O（输入/输出）操作中的两种基本流类型，它们之间既有联系又有区别，以下是它们的关系：

## 2. 字节流和字符流的关系

### 区别

- **处理的数据类型不同**
    - **字节流**：以字节为单位处理数据。它可以处理任何类型的数据，包括文本文件、图片、音频、视频等。因为计算机中的所有数据在底层都是以字节形式存储和传输的，所以字节流适用于处理二进制数据，如读取和写入一个可执行程序文件、一个音频文件等。例如，`FileInputStream` 和 `FileOutputStream` 是字节流，它们可以直接操作文件的字节内容。
    - **字符流**：以字符为单位处理数据。它主要用于处理文本数据，以字符（通常是 Unicode 字符）为单位读写数据。字符流在处理文本文件时更加方便，因为可以直接读取和写入字符，而不需要像字节流那样手动将字节转换为字符。例如，`FileReader` 和 `FileWriter` 是字符流，它们可以方便地读取和写入文本文件的内容。
- **编码方式不同**
    - **字节流**：不涉及编码问题，直接操作字节。它不会对数据进行编码或解码，只是简单地将数据以字节形式进行读写。
    - **字符流**：**涉及编码问题。**在读取和写入字符时，字符流会根据指定的字符集（如 UTF-8、GBK 等）将字符编码为字节或从字节解码为字符。例如，当使用 `FileReader` 读取一个文本文件时，它会根据系统的默认字符集或指定的字符集将文件中的字节解码为字符。

### 联系

- **底层实现**：字符流在底层是基于字节流实现的。字符流在读取和写入字符时，会通过字节流来读取或写入底层的字节数据，然后根据指定的字符集进行编码或解码操作。**例如，`FileReader` 在读取文件时，实际上是通过 `FileInputStream` 来读取文件的字节数据，然后将这些字节数据解码为字符**。
- **共同的抽象基类**：字节流和字符流都有各自的抽象基类。字节流的抽象基类是 `InputStream` 和 `OutputStream`，字符流的抽象基类是 `Reader` 和 `Writer`。这些抽象基类定义了流的基本操作方法，如读取、写入、关闭等，具体的流类继承这些抽象基类并实现具体的操作逻辑。

## 3. 常见的字符流子类及其构造方法

### 1. **`FileReader`**

- **描述**：用于从文件中读取字符。
- **重要构造函数**：
  - `FileReader(String fileName)`：通过文件名创建 `FileReader`。
  - `FileReader(File file)`：通过 `File` 对象创建 `FileReader`。
- **重要方法**：
  
  - 继承自 `Reader`，主要使用 `read()` 和 `read(char[] cbuf)`。
  
#### 示例代码：

```java
import java.io.FileReader;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";
        StringBuffer stringBuffer = new StringBuffer();

        try (FileReader fileReader = new FileReader(filePath)) {
            char[] buffer = new char[1024];
            int length;
    		
            while ((length = fileReader.read(buffer)) != -1) {
                stringBuffer.append(buffer, 0, length);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }    
        System.out.println(stringBuffer.toString());
    }
}
```

### 2. `FileWriter`

**重要构造函数**：

- `FileWriter(String fileName)`：通过文件名创建文件输出流。
- `FileWriter(String fileName, boolean append)`：通过文件名创建文件输出流，并指定是否追加模式。

**示例代码**：

```java
import java.io.FileWriter;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";
        try (FileWriter fw = new FileWriter(filePath, true)) {
            fw.write("\nThis is a new line added using FileWriter.");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 3. `InputStreamReader`
**重要构造函数**：
- `InputStreamReader(InputStream in)`：通过字节输入流创建字符输入流。
- `InputStreamReader(InputStream in, String charsetName)`：通过字节输入流创建字符输入流，并指定字符编码。

**示例代码**：

```java
import java.io.FileInputStream;
import java.io.InputStreamReader;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";
		//能够指定编码从文件中读取字符的方法
        try (InputStreamReader isr = new InputStreamReader(new FileInputStream(filePath), "UTF-8")) {
            char[] buffer = new char[1024];
            int length;
            StringBuffer stringBuffer = new StringBuffer();
            while ((length = isr.read(buffer)) != -1) {
                stringBuffer.append(buffer, 0, length);
            }
            System.out.println(stringBuffer.toString());
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**从文件里面读取内容为什么要兜个圈子 使用  InputStreamReader 而不是直接使用 FileReader?**

### 4. `OutputStreamWriter`
**重要构造函数**：
- `OutputStreamWriter(OutputStream out)`：通过字节输出流创建字符输出流。
- `OutputStreamWriter(OutputStream out, String charsetName)`：通过字节输出流创建字符输出流，并指定字符编码。

**示例代码**：
```java
import java.io.FileOutputStream;
import java.io.OutputStreamWriter;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";

        try (OutputStreamWriter osw = new OutputStreamWriter(new FileOutputStream(filePath, true), "UTF-8")) {
            osw.write("\nThis is a new line added using OutputStreamWriter.");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**向件里面写容为什么要兜个圈子 使用  `OutputStreamWriter` 而不是直接使用 `FileWriter`?**

### 5. `LineNumberReader`

**重要构造函数**：
- `LineNumberReader(Reader in)`：通过包装一个 `Reader` 对象创建 `LineNumberReader`。

**示例代码**：
```java
import java.io.FileInputStream;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.LineNumberReader;

public class Demo {
	public static void main(String[] args) {
		String filePath = "D:/temp/example.txt"; // 文件路径

		//使用LinumerReader从文本文件中，指定编码读取比较标准的方法
		try (InputStream in = new FileInputStream(filePath);
				InputStreamReader inReader = new InputStreamReader(in, "UTF-8");
				LineNumberReader lnr = new LineNumberReader(inReader);) {
			String line;
			while ((line = lnr.readLine()) != null) {
				System.out.println("Line " + lnr.getLineNumber() + ": " + line);
			}
		} catch (IOException e) {
			System.err.println("发生异常: " + e.getMessage());
		}
	}
}
```
