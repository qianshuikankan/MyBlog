在 Java 中，泛型是一种强大的机制，用于在编译时提供类型安全和代码复用。通过使用泛型，可以指定集合（如 `Set`、`Map`、`List`）中存储的元素类型，从而避免类型转换的错误和提高代码的可读性。

以下是使用 `Set`、`Map` 和 `List` 的示例，展示如何在这些集合中使用泛型。

# 1. 在集合中使用泛型

## 1 示例 1：使用泛型 的`List` 
```java
import java.util.ArrayList;
import java.util.List;

public class Demo {
    public static void main(String[] args) {
    	//没有使用泛型的例子：
        List list = new ArrayList();
        list.add(100);
        list.add(200);
        //没有约束力，能够增加任何类型内容，以下代码编译通过运行报错
        list.add("400");
        int sum=0;
        for (Object obj: list) {
        	//需要做类型转换 转换为Integer
        	sum=sum+(Integer)obj;            
        }
       
    	//使用泛型的例子：
        List<Integer> list2 = new ArrayList<>();
        list2.add(100);
        list2.add(200);
        //有约束力，不能增加其他类型的内容 ，以下代码编译不过
        list2.add("400");        
        for (Integer i: list2) {
        	//不需要做类型转换
        	sum=sum+i;            
        }
    }
}
```

## 3. 示例 3：使用 `Map` 的泛型
```java
import java.util.HashMap;
import java.util.Map;
import java.util.Map.Entry;

public class Demo {
	public static void main(String[] args) {
		// 使用泛型
		Map<String, Integer> map = new HashMap<>();
		map.put("贾", 25);
		map.put("宝", 30);
		map.put("玉", 35);
		// 不需要做类型转换
		Integer count = map.get("贾");
		System.out.println("贾出现次数 " + count);
		int totalCount = 0;
		for (Entry<String, Integer> entry : map.entrySet()) {
			totalCount = totalCount + entry.getValue();
		}
		System.out.println("总出现次数 " + totalCount);

		// 不使用泛型
		Map map2 = new HashMap();
		map2.putAll(map);
		count = (Integer) map.get("贾");
		System.out.println("贾出现次数 " + count);
		totalCount = 0;
		for (Object key : map2.keySet()) {
			totalCount = totalCount + (Integer) map2.get(key);
		}
		System.out.println("总出现次数 " + totalCount);
	}
}

```

# 2. 泛型的好处
1. **类型安全**：通过指定集合中存储的元素类型，编译器会在编译时检查类型是否正确，避免了运行时的 `ClassCastException`。
2. **代码复用**：泛型允许编写通用的代码，适用于多种类型。
3. **可读性**：泛型使代码更清晰，明确指定了集合中存储的元素类型。

## 3. **泛型方法**

泛型方法是一种可以在方法级别使用泛型的机制。通过泛型方法，可以在方法的参数和返回值中使用类型参数。

### 定义语法

```java
修饰符 <类型参数列表> 返回值类型 方法名(参数列表) {
    // 方法体
}
```

1. **修饰符**：
   - 可以是`public`、`protected`、`private`、`static`、`final`等，具体取决于方法的访问权限和特性。

2. **类型参数列表**：
   - 用`<...>`定义一个或多个类型参数，类型参数的名称**通常**使用单个大写字母（如`T`、`E`、`K`、`V`等）。
   - 类型参数列表必须在返回值类型之前。

3. **返回值类型**：
   - 方法的返回值类型可以是具体的类型，也可以是类型参数。

4. **方法名**：
   - 方法的名称，遵循Java的命名规范。

5. **参数列表**：
   - 方法的参数列表，可以包含具体的类型或类型参数。

### 一个例子


```
	//取得一个Map中最大的value对应的key
	//value可能是int string ...任意可比较的内容
	public static <K, V extends Comparable<V>> K findKeyOfMaxValue(Map<K, V> map) {

	        throw new IllegalArgumentException("Map cannot be null or empty");

	        }

	}
```

# 6. 泛型的不变性

泛型是不变的（invariant），即 List<子类> 并不是 List<父类> 的子类型， List<父类>也不是 List<子类>的子类型。

在 Java 中，泛型是不变的（invariant），这意味着泛型类型参数是严格的，不能自动转换为它们的父类或子类。换句话说，`List<子类>` 和 `List<父类>` 在 Java 中是完全不同的类型，即使 `子类` 是 `父类` 的子类。这种不变性是 Java 泛型设计的一个重要特性，它确保了类型安全，但也带来了一些限制。

## **1. 理解不变性（Invariance）**

- **不变性（Invariance）**：对于泛型类型 `List<T>`，`List<子类>` 和 `List<父类>` 是完全不同的类型，不能相互赋值或隐式转换。

## **2. 不变性的具体表现**

Java 泛型设计为不变性是为了确保类型安全。如果允许 `List<子类>` 赋值给 `List<父类>` 或反之，可能会导致运行时错误。例如：

```java
import java.util.ArrayList;
import java.util.List;

class Parent {
}

class Child extends Parent {
}

public class Demo {
	public static void main(String[] args) {
		List<Child> subList = new ArrayList<>();
		List<Parent> parentList = new ArrayList<>();
		// 下面的代码会导致编译错误
		parentList = subList; // 错误：List<子类> 不能赋值给 List<父类>
		subList = parentList; // 错误：List<父类> 不能赋值给 List<子类>
	}
}
```

## **3. 不变性的原因**
### 1 假设  `List<子类>` 应该是 `List<父类>` 的子类

假设  `List<子类>`是 `List<父类>` 的子类，可以赋值给 `List<父类>`。但这会导致问题：

```java
List<子类> subList = new ArrayList<>();
subList.add(new 子类());

List<父类> parentList = subList; // 假设这是允许的
parentList.add(new 父类()); // 这里会出问题，因为 subList 只能存储 子类 类型的对象

// 现在 subList 中包含了 父类 类型的对象，这违反了类型安全
```

### **2 假设`List<父类>` 应该是 `List<子类>` 的子类**
`List<父类>`是 `List<子类>` 的子类，可以赋值给 `List<子类>`。但这同样会导致问题：

```java
List<父类> parentList = new ArrayList<>();
parentList.add(new 父类());

List<子类> subList = parentList; // 假设这是允许的
子类 subClassInstance = subList.get(0); // 这里会出问题，因为 parentList 中存储的是 父类 类型的对象

// 现在尝试将 父类 类型的对象赋值给 子类 类型的变量，这会导致 ClassCastException
```

# 7. 泛型不变性的解决方案

## 1 (上界通配符) `<? extends T>` ：表示"某种未知的 T 的子类型"

- 适合从集合中**读取**数据（消费者）
- 不能向集合中**写入**（除 null 外）

## 2 (下界通配符) ` <? super T>` ：表示"某种未知的 T 的父类型"

- 适合向集合中**写入**数据（生产者）
- 从集合中读取时只能得到 Object

```java
import java.util.ArrayList;
import java.util.List;

class Animal {
	public void eat() {
		System.out.println("this is animal eat!");
	}
}

class Dog extends Animal {
}

class Cat extends Animal {
}

public class Demo {
	public static void printAnimalsEat(List< ? extends Animal> animals) {
		for (Animal animal : animals) {
			animal.eat();
		}
	}

	public static void addAnimals(List< ? super Dog> animals) {
		animals.add(new Dog());
	}

	public static void main(String[] args) {
		List<Animal> animals = new ArrayList<>();
		animals.add(new Dog());

		List<Dog> dogs = new ArrayList<>();
		dogs.add(new Dog());
		printAnimalsEat(dogs);
		printAnimalsEat(animals);		
		
		addAnimals(dogs);
		addAnimals(animals);
		System.out.println(animals);
	}
}
```

```
			dest.set(i, src.get(i));
		}
	}

	public static void main(String[] args) {
		List<Animal> animals = new ArrayList<>();
		List<Dog> dogs = new ArrayList<>();
		copy(animals,dogs);
	
	}

}
```

## 3. **无界通配符（`<?>`）**

| 特性       | 说明                   |
| -------- | -------------------- |
| **读操作**  | 只能当作 `Object` 来读取    |
| **写操作**  | **禁止写入**（除 `null` 外） |
| **类型安全** | 保证你不会破坏列表的类型一致性      |


```java
import java.util.ArrayList;
import java.util.List;

public class Demo {
	public static void main(String[] args) {
		List<String> list = new ArrayList();
		printSize(list);
		printSizeRaw(list);
	}

	// 原生类型 - 不安全
	static void printSizeRaw(List list) {
		System.out.println(list.size());
	}

	// 无界通配符 - 更安全
	static void printSize(List<?> list) {
		System.out.println(list.size());
		// list.add(new Object());// 编译错误！无法添加		
		// list.add("string"); // 编译错误！无法添加		
	}
}
```
