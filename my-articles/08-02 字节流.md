# 1 流概述

I/O流是处理输入输出的核心机制，主要通过`java.io`包中的类来实现。

### 1. **顶级抽象类**
Java I/O流继承自`java.io.InputStream`（用于输入）和`java.io.OutputS`

`tream`（用于输出），以及`java.io.Reader`（用于字符输入）和`java.io.Writer`（用于字符输出）。

### 2. **字节流（InputStream 和 OutputStream）**
字节流用于处理二进制数据，如文件、网络数据等。

#### **InputStream**（抽象类）[重要]
- **FileInputStream**：用于从文件中读取字节。[重要]
- **ByteArrayInputStream**：从字节数组中读取数[重要]据。
- **BufferedInputStream**：为其他输入流添加缓冲功能，提高读取效率。
- **DataInputStream**：允许从输入流中读取Java基本数据类型（如int、double等）。
- **ObjectInputStream**：用于从流中读取Java对象（必须实现`Serializable`接口）。

#### **OutputStream**（抽象类）[重要]
- **FileOutputStream**：用于向文件写入字节。[重要]
- **ByteArrayOutputStream**：将数据写入字节数组。[重要]
- **BufferedOutputStream**：为其他输出流添加缓冲功能，提高写入效率。
- **DataOutputStream**：允许将Java基本数据类型写入输出流。
- **ObjectOutputStream**：用于将Java对象写入流（对象必须实现`Serializable`接口）。

### 3. **字符流（Reader 和 Writer）**
字符流用于处理字符数据，通常用于文本文件等。

#### **Reader**
- **FileReader**：用于从文件中读取字符。[重要]
- **CharArrayReader**：从字符数组中读取数据。
- **BufferedReader**：为其他字符输入流添加缓冲功能，提高读取效率。
- **InputStreamReader**：将字节流转换为字符流，通常与`FileInputStream`配合使用。
- **LineNumberReader**： 可以逐行读取文本,通过 `getLineNumber()` 方法可以获取当前的行号

#### **Writer**
- **FileWriter**：用于向文件写入字符。[重要]
- **CharArrayWriter**：将数据写入字符数组。
- **BufferedWriter**：为其他字符输出流添加缓冲功能，提高写入效率。
- **OutputStreamWriter**：将字节流转换为字符流，通常与`FileOutputStream`配合使用。

以下是Java I/O流的继承关系图的简化版本：

# 1 字节流

在 Java 中，字节流是处理二进制数据输入输出的核心机制，主要位于 `java.io` 包中。字节流的基类是 `InputStream` 和 `OutputStream`，分别用于读取和写入字节数据。

## 1. `InputStream`（抽象类）
`InputStream` 是所有字节输入流的基类，用于从数据源读取字节数据。

### 主要方法
- `int read()`：从输入流中读取一个字节的数据，返回一个 `int` 值（0-255），如果到达流的末尾，返回 `-1`。
- `int read(byte[] b)`：从输入流中读取最多 `b.length` 个字节的数据到字节数组 `b` 中，返回实际读取的字节数，如果到达流的末尾，返回 `-1`。
- `int read(byte[] b, int off, int len)`：从输入流中读取最多 `len` 个字节的数据到字节数组 `b` 中，从偏移量 `off` 开始存储，返回实际读取的字节数，如果到达流的末尾，返回 `-1`。
- `void close()`：关闭输入流并释放系统资源。

## 2. `OutputStream`（抽象类）
`OutputStream` 是所有字节输出流的基类，用于向目标写入字节数据。

### 主要方法
- `void write(int b)`：向输出流中写入一个字节的数据，参数 `b` 的低八位被写入。
- `void write(byte[] b)`：向输出流中写入字节数组 `b` 中的所有字节。
- `void write(byte[] b, int off, int len)`：向输出流中写入字节数组 `b` 中从偏移量 `off` 开始的 `len` 个字节。
- `void close()`：关闭输出流并释放系统资源。
- `void flush()`：刷新输出流，确保所有数据都被写出。

## 3 常见的字节流子类及其构造方法

### 1. `FileInputStream`

用于从文件读取字节数据。

#### 构造方法
- `FileInputStream(String name)`：通过文件路径字符串创建 `FileInputStream`。
- `FileInputStream(File file)`：通过 `File` 对象创建 `FileInputStream`。

#### 示例  `try-catch-finally` 结构

```java
import java.io.FileInputStream;
import java.io.File;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        FileInputStream fis = null;
        try {
            fis = new FileInputStream("D:/temp/example.txt");
            int byteData;
            //读取以带有汉字的文件，看有啥效果
            while ((byteData = fis.read()) != -1) {
                System.out.print((char) byteData);
            }
        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            //用完需要关闭，但是关闭有可能触发一次
            if (fis != null) {
                try {
                    fis.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
    }
}


```

#### 关于 try-with-resources结构

`try-with-resources` 语句允许在 `try` 块的括号中声明一个或多个资源，这些资源必须实现了 `AutoCloseable` 接口或其子接口 `Closeable`。当 `try` 块执行完毕（无论是正常结束还是发生异常），这些资源会自动被关闭。

**语法结构**

```java
try (ResourceType resource1 = new ResourceType(...);
     ResourceType2 resource2 = new ResourceType2(...)) {
    // 使用资源的代码
} catch (ExceptionType e) {
    // 处理异常
}
```
- **ResourceType**：资源的类型，必须实现 `AutoCloseable` 或 `Closeable` 接口。
- **resource1、resource2**：声明的资源变量。
- **ExceptionType**：可能抛出的异常类型。

**优点**

1. **自动关闭资源**：无需手动调用 `close()` 方法，减少了代码量，避免了因忘记关闭资源而导致的资源泄漏。
2. **异常处理更简洁**：即使在资源关闭时抛出异常，`try-with-resources` 也能正确处理，不会干扰主逻辑的异常处理。
3. **支持多个资源**：可以在一个 `try-with-resources` 块中声明多个资源，它们都会在 `try` 块结束后被自动关闭。

#### 示例   try-with-resources结构读取文件，一次读取一个字节

```java
import java.io.FileInputStream;
import java.io.File;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        try (FileInputStream fis = new FileInputStream("D:/temp/example.txt")) {
            int byteData;
          
            while ((byteData = fis.read()) != -1) {
                System.out.print((char) byteData);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

#### 示例   try-with-resources结构读取文件，一次读取多个字节，结果放到byte[]中

```java
import java.io.*;

public class Demo {
    public static void main(String[] args) {
        // 文件路径
        String filePath = "D:/temp/example.txt";
        // 每次读取的字节数（1MB）
        int chunkSize = 1024 * 1024;    
        // 使用 File.length() 获取文件大小
        File file = new File(filePath);
        long fileSize = file.length();    
        // 创建一个足够大的 byte 数组来存储整个文件内容
        byte[] fileContent = new byte[(int) fileSize];    
        // 使用 try-with-resources 确保资源自动关闭
        try (FileInputStream fis = new FileInputStream(filePath)) {
            // 创建一个缓冲区，每次读取1MB
            byte[] buffer = new byte[chunkSize];
    
            // 当前已读取的字节数
            int totalBytesRead = 0;    
            // 分块读取文件内容比较标准的写法
            while (totalBytesRead < fileSize) {
                // 每次读取的字节数
                int bytesRead = fis.read(buffer, 0, Math.min(chunkSize, (int) (fileSize - totalBytesRead)));
                if (bytesRead == -1) {
                    break; // 如果 read 返回 -1，表示已读取到文件末尾
                }
                // 将缓冲区中的数据复制到 fileContent 数组中
                System.arraycopy(buffer, 0, fileContent, totalBytesRead, bytesRead);
                totalBytesRead += bytesRead;
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    
        // 打印文件内容（以字符串形式，仅用于测试）
        System.out.println(new String(fileContent));
    }

}
```

注意：把文件内容全部放到一个byte[]中意味着所有内容要放到内存，并不适合处理所有文件，对于超级大的文件（几个G以上）比如日志、视频 文件、数据库文件等不能用这种方式。但是对于一个图片、一个小说、一篇文章、一个配置文件、所有学生导出结果等可以用这种方法。

### 2. `FileOutputStream`

用于向文件写入字节数据。

#### 构造方法

- `FileOutputStream(String name)`：通过文件路径字符串创建 `FileOutputStream`。
- `FileOutputStream(File file)`：通过 `File` 对象创建 `FileOutputStream`。
- `FileOutputStream(String name, boolean append)`：通过文件路径字符串创建 `FileOutputStream`，`append` 参数决定是否追加模式。
- `FileOutputStream(File file, boolean append)`：通过 `File` 对象创建 `FileOutputStream`，`append` 参数决定是否追加模式。

#### 示例
```java
import java.io.FileOutputStream;
import java.io.File;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        String content = "Hello, World!";
        //尝试FileOutputStream fos = new FileOutputStream("D:/temp/example.txt",true) 看一下效果
        try (FileOutputStream fos = new FileOutputStream("D:/temp/example.txt")) {
            fos.write(content.getBytes());
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 3. `BufferedInputStream`

包装 `InputStream`，提供缓冲功能，提高读取效率。

#### 构造方法
- `BufferedInputStream(InputStream in)`：通过包装一个 `InputStream` 创建 `BufferedInputStream`。
- `BufferedInputStream(InputStream in, int size)`：通过包装一个 `InputStream` 创建 `BufferedInputStream`，并指定缓冲区大小。

### 4. `BufferedOutputStream`

包装 `OutputStream`，提供缓冲功能，提高写入效率。

#### 构造方法
- `BufferedOutputStream(OutputStream out)`：通过包装一个 `OutputStream` 创建 `BufferedOutputStream`。
- `BufferedOutputStream(OutputStream out, int size)`：通过包装一个 `OutputStream` 创建 `BufferedOutputStream`，并指定缓冲区大小。


### 5. `ByteArrayInputStream`

从字节数组读取数据。

**注意：这个类是实现一个byte[]数组和InputStream之间转换的途径。**

#### 构造方法

- `ByteArrayInputStream(byte[] buf)`：通过字节数组创建 `ByteArrayInputStream`。
- `ByteArrayInputStream(byte[] buf, int offset, int length)`：通过字节数组的一部分创建 `ByteArrayInputStream`。

#### 示例
```java
import java.io.ByteArrayInputStream;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        byte[] data = "Hello, World!".getBytes();
        try (ByteArrayInputStream bais = new ByteArrayInputStream(data)) {
            int byteData;
            while ((byteData = bais.read()) != -1) {
                System.out.print((char) byteData);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 6. `ByteArrayOutputStream`

将数据写入字节数组。

**注意：这个类是实现一个byte[]数组和OutputStream之间转换的途径。**

#### 构造方法
- `ByteArrayOutputStream()`：创建一个空的 `ByteArrayOutputStream`。
- `ByteArrayOutputStream(int size)`：创建一个指定初始大小的 `ByteArrayOutputStream`。

#### 重要方法：

- **`toByteArray()`**：将输出流中的数据转换为字节数组。
- **`toString()`**：将输出流中的数据转换为字符串（默认使用平台默认字符集）。
- **`writeTo(OutputStream out)`**：将输出流中的数据写入到另一个输出流中。

#### 示例

```java
import java.io.ByteArrayOutputStream;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        try (ByteArrayOutputStream baos = new ByteArrayOutputStream()) {
            baos.write("Hello, World!".getBytes());
            byte[] data = baos.toByteArray();
            System.out.println(new String(data));
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
