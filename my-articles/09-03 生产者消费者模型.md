考虑如下情形应该怎样解决：

一个（几个）线程生成任务并将其放入任务队列，另一个（几个）线程从队列中取出任务并执行。例如：

日志记录：若干线程生成日志放入缓冲区，另一个线程把日志从缓冲区拿走记录到文件中。

资源分配：只有固定的几个资源，每个线程使用前来申请资源，使用资源以后释放回来，比如数据库连接。好比学院只有3个专业相机，每个班级都想借相机拍合影。

## 1 使用sleep实现的生产者/消费者模型

考虑一个场景：一个线程不断的生产出内容，另一个线程去处理这些内容，应该怎样实现？

 下面代码有没有问题？为什么？

```java
import java.util.LinkedList;
import java.util.Queue;

// 共享缓冲区
class Buffer {
	private Queue<Integer> queue = new LinkedList<>();
	private int capacity;
	public Buffer(int capacity) {
		this.capacity = capacity;
	}
	// 生产者向缓冲区添加产品
	public synchronized void put(int value) throws InterruptedException {
		while (queue.size() == capacity) {
			// 缓冲区已满，等待消费者消费
			Thread.sleep(100);
		}
		queue.add(value);
		System.out.println("Produced: " + value + ", Buffer size: " + queue.size());
	}
	// 消费者从缓冲区取出产品
	public synchronized int get() throws InterruptedException {
		while (queue.isEmpty()) {
			// 缓冲区为空，等待生产者生产
			Thread.sleep(100);
		}
		int value = queue.poll();
		System.out.println("Consumed: " + value + ", Buffer size: " + queue.size());
		return value;
	}
}

// 生产者线程
class Producer implements Runnable {
	private Buffer buffer;
	public Producer(Buffer buffer) {
		this.buffer = buffer;
	}
	@Override
	public void run() {
		int i = 0;
		while (true) {
			try {
				buffer.put(i++);
				Thread.sleep((int) (Math.random() * 1000));
			} catch (InterruptedException e) {
				e.printStackTrace();
			}
		}
	}
}

// 消费者线程
class Consumer implements Runnable {
	private Buffer buffer;
	public Consumer(Buffer buffer) {
		this.buffer = buffer;
	}
	@Override
	public void run() {
		while (true) {
			try {
				buffer.get();
				Thread.sleep((int) (Math.random() * 1000));
			} catch (InterruptedException e) {
				e.printStackTrace();
			}
		}
	}
}

public class Demo {
	public static void main(String[] args) {
		// 创建一个容量为5的缓冲区
		Buffer buffer = new Buffer(5);
		// 创建生产者和消费者线程
		Thread producerThread = new Thread(new Producer(buffer));
		Thread consumerThread = new Thread(new Consumer(buffer));
		// 启动线程
		producerThread.start();
		consumerThread.start();
	}
}
```

## 2.真正的生产者/消费者模型

`wait()`、`notify()` 和 `notifyAll()` 是 Java 中用于线程间通信的三个重要方法，它们通常用于协调线程的行为，特别是在多线程环境中实现生产者-消费者模式或其他同步机制。这些方法都定义在 `Object` 类中，因此所有 Java 对象都可以使用它们。

###  一个使用wait/notifyall实现生产者/消费者的例子

```java
import java.util.LinkedList;
import java.util.List;

class Buffer {
    private List<Integer> queue = new LinkedList<>();
    private int capacity;
    public Buffer(int capacity) {
        this.capacity = capacity;
    }
    public synchronized void put(int value) throws InterruptedException {
        while (queue.size() == capacity) {
        	System.out.println("buffer size="+queue.size()+" is full!");
            wait(); // 等待，直到有空间可以放入新元素
        }
        queue.add(value);
        notifyAll(); // 通知等待的消费者线程
    }    
    public synchronized int get() throws InterruptedException {
        while (queue.isEmpty()) {
            wait(); // 等待，直到有元素可以取出
            System.out.println("buffer is empty!");
        }
        int value = queue.get(0);
        queue.remove(0);
        notifyAll(); // 通知等待的生产者线程
        return value;
    }
}

class Producer implements Runnable {
    private Buffer buffer;
    public Producer(Buffer buffer) {
        this.buffer = buffer;
    }
    @Override
    public void run() {
    	int i=0;
        while(true) {
            try {
                System.out.println("Produced: " + i);
                buffer.put(i);
                Thread.sleep((int) (Math.random() * 1000));
                i++;
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}

class Consumer implements Runnable {
    private Buffer buffer;
    public Consumer(Buffer buffer) {
        this.buffer = buffer;
    }
    @Override
    public void run() {
    	while(true) {
            try {
                int value = buffer.get();
                System.out.println("Consumed: " + value);
                Thread.sleep((int) (Math.random() * 1000));
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
public class Demo {
    public static void main(String[] args) {
        Buffer buffer = new Buffer(10);
        // 创建生产者线程
        Thread producerThread = new Thread(new Producer(buffer));
        producerThread.setName("Producer");    
        // 创建消费者线程
        Thread consumerThread = new Thread(new Consumer(buffer));
        consumerThread.setName("Consumer");    
        // 启动线程
        producerThread.start();
        consumerThread.start();
    }
}
```



### 1. `wait()`/**`wait(long timeout)`**

```
public final void wait() throws InterruptedException
```

`wait()` 方法使当前线程进入等待状态，直到其他线程调用该对象的 `notify()` 或 `notifyAll()` 方法唤醒它。调用 `wait()` 方法时，当前线程会释放对象的锁，并进入等待状态。

```
public final void wait(long timeout) throws InterruptedException
```

wait(long timeout) ,使当前线程进入等待状态，直到以下任意一种情况发生,调用 `wait()` 方法时，当前线程会释放对象的锁，并进入等待状态。

- 其他线程调用同一个对象的`notify()`或`notifyAll()`方法。
- 指定的超时时间`timeout`（以毫秒为单位）已过。

### 2. `notify()`

`notify()` 方法唤醒一个正在等待该对象锁的线程。如果有多个线程正在等待，`notify()` 只会唤醒其中一个线程。作用：

- **唤醒一个等待线程**：从等待该对象锁的线程中随机选择一个线程唤醒。
- **不释放锁**：调用 `notify()` 的线程不会释放对象的锁，被唤醒的线程需要等待当前线程释放锁后才能继续执行。

### 3. `notifyAll()`
`notifyAll()` 方法唤醒所有正在等待该对象锁的线程。所有等待该对象锁的线程都会被唤醒，并重新尝试获取锁。作用：

- **唤醒所有等待线程**：唤醒所有正在等待该对象锁的线程。
- **不释放锁**：调用 `notifyAll()` 的线程不会释放对象的锁，被唤醒的线程需要等待当前线程释放锁后才能继续执行。

### 使用注意事项
1. **必须在同步块中调用**：
   - `wait()`、`notify()` 和 `notifyAll()` 必须在同步块中调用，否则会抛出 `IllegalMonitorStateException`。
   - 示例：

```java
public class Demo {
	public void f1() {
		synchronized (this) {
			try {
				wait(1);
			} catch (InterruptedException e) {
				e.printStackTrace();
			}
			notify();
			notifyAll();
		}
	}

	// 这个函数是错误的
	// 没有获得同步锁的时候，没有资格调用如下方法
	public void f2() {
		try {
			wait(1);
		} catch (InterruptedException e) {
			e.printStackTrace();
		}
		notify();
		notifyAll();
	}
	
	public static void main(String[] args) {
		new Demo().f1();
		new Demo().f2();
	}

}
```




2. **使用 `while` 循环检查条件**：
   
   - 在调用 `wait()` 之前，使用 `while` 循环检查条件，确保不会因误唤醒而继续执行。
   - 示例：
     ```java
     	synchronized(this)
     	{
     		while (queue.isEmpty()) {
     			wait(); // 等待，直到有元素可以取出
     			System.out.println("buffer is empty!");
     		}
     	}
     ```
3. **优先使用 `notifyAll()`**：
   
   - 尽量使用 `notifyAll()` 而不是 `notify()`，因为 `notify()` 只会唤醒一个等待的线程，可能导致其他线程无法被唤醒。
   - 示例：
     ```java
     synchronized (this) {
         notifyAll();
     }
     ```



**sleep()和wait()的最大区别：**

- sleep()时候不需要锁，也不会释放锁

- wait()时候需要锁，会释放锁
