# MAP介绍（暂时不考虑泛型和迭代器Iterator）

## 1. Java.util.Map 重要方法

- 【重要】`put(K key, V value)`：插入或更新键值对。
- 【重要】`get(Object key)`：根据键获取值。
- 【重要】getOrDefault(Object key, V defaultValue)，根据键获取值。如果Map中不包含 key,则返回defaultValue
- 【重要】`containsKey(Object key)`：检查是否包含指定键。
- 【重要】`containsValue(Object value)`：检查是否包含指定值。
- 【重要】`remove(Object key)`：根据键删除键值对。
- 【重要】`size()`：返回键值对数量。
- `【重要】isEmpty()`：检查映射是否为空。
- `【重要】`clear()`：清空映射。
- 【重要】`keySet()`：返回键的集合视图。
- `【重要】values()`：返回值的集合视图。
- 【重要】`entrySet()`：返回键值对的集合视图。

## 2.重要的实现

### 1. **HashMap**

- **特点**：基于哈希表实现，提供快速的插入、查找和删除操作。不保证元素的顺序，允许键和值为 `null`。
- **适用场景**：适用于需要快速访问且不关心元素顺序的场景。
- **线程安全**：`HashMap` 是线程不安全的。如果需要线程安全，可以使用 `Collections.synchronizedMap` 包装，或者直接使用 `ConcurrentHashMap`。

### 2. **TreeMap**

- **特点**：基于红黑树实现，可以按照键的自然顺序或指定的 `Comparator` 进行排序。不允许键为 `null`。
- **适用场景**：适用于需要有序键值对的场景，例如排序数据。注意是针对key的排序，而不是对value的排序
- **线程安全**：`TreeMap` 是线程不安全的。

## 3.HashMap /TreeMap举例子 

### 示例代码
```java
import java.util.HashMap;
import java.util.Map;
import java.util.TreeMap;

public class Demo {
	public static void main(String[] args) {
		Map map = new HashMap();
		Map map2 = new TreeMap();
		map.put("Li", 25);
		map.put("Zhang", 30);
		map.put("Zhao", 35);
		map.put("Liu", 35);

		System.out.println(map.get("Liu"));
		System.out.println(map.containsKey("Zhang"));
		System.out.println(map.containsValue(25));

		System.out.println("map.remove(\"Zhao\")");
		map.remove("Zhao");
		System.out.println(map);

		System.out.println("keySet:" + map.keySet());
		System.out.println("values:" + map.values());
		System.out.println("entrySet:" + map.entrySet());
		
		map2.putAll(map);
		System.out.println("HashMap数据遍历:");
		for (Object key : map.keySet()) {
			System.out.println(key + ": " + map.get(key));
		}
		System.out.println("TreeMap数据遍历:");
		for (Object key : map2.keySet()) {
			System.out.println(key + ": " + map2.get(key));
		}
		map.clear();
		System.out.println(map);
	}
}
```



### Map另一个例子，统计出现最高的字符（没有限定是汉字）

```
import java.util.HashMap;
import java.util.Map;

public class Demo {
	public static void main(String[] args) {
		String text = "宝玉因不见了林黛玉便知是他躲了别处去了想了一想索性迟些出去等他回来大家连了夜逛着更好因此进来找黛玉不想才进了院门就有翠缕晴雯忙迎上来说：“林姑娘在沁芳亭边呢二爷快去罢这会子人好没人打扰姑娘正伤心呢”宝玉听了忙问：“怎么又伤心了？”晴雯道：“这会子还有谁叫人伤心的？想是刚才将手帕子忘在里头了”宝玉听了转身便同了晴雯、翠缕二人来至沁芳亭只见黛玉正拿着锄头在那里葬花宝玉忙赶上来一把将锄头夺下用自己手帕子替他拭泪笑道：“好妹妹别哭我身上就是有病关你甚事？别哭坏了身子倒叫人笑话”黛玉将手帕子摔在地下";
		Map map = new HashMap();
		char[] chars = text.toCharArray();
		for (char c : chars) {
			//map.getOrDefault(c, 0) 表示默认值为 0
			map.put(c, (int) map.getOrDefault(c, 0) + 1);
		}

		int maxTimes = 0;
		char maxChar = ' ';
		for (Object key : map.keySet()) {
			int cur = (int) map.get(key);
			if (cur > maxTimes) {
				maxTimes = cur;
				maxChar = (char) key;
			}
		}
	
		System.out.println("出现频率最高的字符是：" + maxChar);
		System.out.println("出现次数为：" + maxTimes);
	}

}
```

**TreeMap排序的标准是Key，不是Value，不要试图使用value排序。**
