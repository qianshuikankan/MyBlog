# 工具类及常用算法

## 1 Java基础类库
java.lang包是Java语言的核心类库（使用这个包里面的内容不需要import)


java.io包是Java语言的标准输入/输出类库

java.util包包括了Java语言中的一些低级的实用工具

java.awt包是Java语言用来构建图形用户界面(GUI)的类库

java.applet包是用来实现运行于Internet浏览器中的Java Applet的工具类库

java.net包是Java语言用来实现网络功能的类库

如果代码开头没有说文件名，例如下面，表示在项目根目录下建立一个Demo.java，把下面代码复制进去就可以：

```
import java.util.*;

class MyObject {
	protected void finalize() throws Throwable {
		System.out.println("MyObject finalize");
		super.finalize(); // 注意这行话的位置
	}
}

public class Demo {
	public static void main(String[] args) {
		// 调用 finalize 的示例
		MyObject myobj = new MyObject();
		System.out.println("gc() 1");
		System.gc();
		myobj = null;
		System.out.println("gc() 2");
		System.gc();
		test();
		System.out.println("gc() 3");
		System.gc();
		myobj = new MyObject();
		List list = new ArrayList();
		list.add(myobj);
		myobj = null;
		System.gc();
	}

	public static void test() {
		MyObject myobj = new MyObject();
	}

}
```
