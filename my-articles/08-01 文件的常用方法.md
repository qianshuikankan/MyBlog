# Java中文件的常用方法（不含读写文件内容）

File位于`java.io.File` 包中，**对于目录和文件，都用File来封装** 。

读写文件内容会在后续章节讲述

# 1. 构造方法

- `File(String pathname)`：通过路径字符串创建 `File` 对象。
- `File(String parent, String child)`：通过父路径和子路径字符串创建 `File` 对象。
- `File(File parent, String child)`：通过父路径 `File` 对象和子路径字符串创建 `File` 对象。

**注意：上面这些方法是构造出文件对象，并非真正在硬盘上创建这个文件！**

# 2. 路径相关方法-

- `String getAbsolutePath()`：获取文件的绝对路径。
- `String getCanonicalPath()`: 获取文件的规范路径。【二者区别见后面例子】
- `String getPath()`：回构造 File 对象时传入的原始路径字符串。
- `String getParent()`：如果文件或目录有父目录，返回父目录的路径。
- `String getName()`：获取文件的名称。

# 3. 文件和目录操作
- `boolean createNewFile()`：创建一个新文件。
- `boolean delete()`：删除文件或目录。
- `boolean mkdir()`：创建单个目录。
- `boolean mkdirs()`：创建多级目录。
- `boolean renameTo(File dest)`：重命名文件或目录。

**注意：上面这些是真正的在硬盘上创建文件、目录**

- `boolean exists()`：检查文件或目录是否存在。
- `boolean isDirectory()`：检查路径是否为目录。
- `boolean isFile()`：检查路径是否为文件。
- `long length()`：获取文件的长度（字节数）。
- `long lastModified()`：获取文件的最后修改时间。

# 5. 文件和目录列表
- `String[] list()`：获取目录中的文件和子目录名称。
- `File[] listFiles()`：获取目录中的文件和子目录对象。

# 6.示例代码

## 1. 构造方法

```java
import java.io.File;

public class Demo {
    public static void main(String[] args) {
        // 使用绝对路径
        //注意：下面这些方法是构造出文件对象，并非真正在硬盘上创建这个文件！
        File file1 = new File("D:/temp/my_example.txt");
        System.out.println("Absolute Path: " + file1.getAbsolutePath());
        //构造对象不等于创建文件：
        System.out.println(file1.getAbsolutePath()+" exist: " + file1.exists());

        // 使用相对路径
        File file2 = new File("example.txt");
        System.out.println("Relative Path: " + file2.getAbsolutePath());

        // 使用父路径和子路径
        File parentDir = new File("D:/temp/");
        File file3 = new File(parentDir, "example.txt");
        System.out.println("Parent and Child Path: " + file3.getAbsolutePath());
    }
}
```

## 2. 路径相关方法

#### getAbsolutePath()和getCanonicalPath()区别

```java
import java.io.File;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) throws IOException {
        // 创建测试文件
        File file = new File("./test/.././data.txt");
        
        System.out.println("file.getPath()原始路径: " + file.getPath());
        // 输出: ./test/.././data.txt
        
        System.out.println("file.getAbsolutePath()绝对路径: " + file.getAbsolutePath());
        // 输出: /home/user/project/./test/.././data.txt
        // 特点: 只是简单拼接当前目录，保留 . 和 ..
        
        System.out.println("file.getCanonicalPath()规范路径: " + file.getCanonicalPath());
        // 输出: /home/user/project/data.txt
        // 特点: 解析并消除了 . 和 ..，是唯一的标准路径
    }
}
```

**核心区别：**

`getAbsolutePath()` 只是简单拼接当前目录和原始路径字符串（保留 `.` 和 `..`），而 `getCanonicalPath()` 会解析 `.` 和 `..` 并消除符号链接，返回文件系统中唯一的真实物理路径。

#### getPath()  getParent()  getName()区别

```java
import java.io.File;
import java.io.IOException;

public class Demo {
    public static void main(String[] args) {
        File file  = new File("example.txt");
        print(file);
        file  = new File("D:/temp/example.txt");
        print(file);
        
    }
    public static void print(File file) {
    	System.out.println("getName(): " + file.getName());
    	System.out.println("getParent(): " + file.getParent());
    	System.out.println("getPath(): " + file.getPath());
    	System.out.println("getAbsolutePath(): " + file.getAbsolutePath());        
        try {
            System.out.println("getCanonicalPath(): " + file.getCanonicalPath());
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

}
```

**getParent()   返回构造路径中最后一个分隔符之前的部分，若路径无父级（如纯文件名或根目录）则返回 null，且仅基于构造时的字符串解析，不涉及文件系统实际是否存在**

## 6. 递归列出目录中的所有文件和子目录

```java
import java.io.File;
public class Demo {
    public static void main(String[] args) {
        String directoryPath = "D:/temp/";
        File directory = new File(directoryPath);
        listFilesRecursively(directory);
    }
    //递归方法，列出目录中的所有文件和子目录
    public static void listFilesRecursively(File directory) {
        // 检查当前路径是否是目录
        if (directory.isDirectory()) {
            // 获取目录中的所有文件和子目录
            File[] files = directory.listFiles();
            if (files != null) {
                for (File file : files) {
                    // 输出当前文件或目录的路径
                    System.out.println(file.getAbsolutePath());
                    // 如果是目录，则递归调用
                    if (file.isDirectory()) {
                        listFilesRecursively(file);
                    }
                }
            }
        } else {
            // 如果传入的路径不是目录，直接输出文件路径
            System.out.println(directory.getAbsolutePath());
        }
    }
}
```

## 7. 递归删除目录中的所有文件和子目录



```java
import java.io.File;

public class Demo {
    public static void main(String[] args) {
        String directoryPath = "D:/temp/";
        File directory = new File(directoryPath);
        if (deleteDirectoryRecursively(directory)) {
            System.out.println("Directory deleted successfully.");
        } else {
            System.out.println("Failed to delete directory.");
        }
    }
    /**
     * 递归删除目录及其所有子目录和文件
     * @return 如果删除成功返回 true，否则返回 false
     */
    public static boolean deleteDirectoryRecursively(File directory) {
        // 检查是否为目录
        if (!directory.isDirectory()) {
            System.out.println(directory.getAbsolutePath() + " is not a directory.");
            return false;
        }

        // 获取目录中的所有文件和子目录
        File[] files = directory.listFiles();
        if (files != null) {
            for (File file : files) {
                // 如果是文件，直接删除
                if (file.isFile()) {
                    if (!file.delete()) {
                        System.out.println("Failed to delete file: " + file.getAbsolutePath());
                        return false;
                    }
                } else if (file.isDirectory()) {
                    // 如果是子目录，递归删除
                    if (!deleteDirectoryRecursively(file)) {
                        return false;
                    }
                }
            }
        }
        // 删除当前目录
        if (!directory.delete()) {
            System.out.println("Failed to delete directory: " + directory.getAbsolutePath());
            return false;
        }
        return true;
    }

}
```
