# 多线程的访问冲突和解决方案

线程的访问冲突是指在多线程环境中，多个线程同时访问共享资源时可能出现的问题。由于线程的执行顺序是不确定的，如果多个线程同时对共享资源进行读写操作，可能会导致数据不一致、结果错误或程序行为异常。以下是线程访问冲突的几种常见类型及其示例。

## 1. **数据竞争（Data Race）**

数据竞争是指两个或多个线程同时访问同一个变量，且至少有一个线程对变量进行写操作。数据竞争可能导致以下问题：
- **数据不一致**：多个线程对共享变量的读写操作顺序不确定，导致最终结果不一致。
- **丢失更新**：一个线程的更新被另一个线程覆盖。
- **因为上述两个原因，可能会导致系统出现其他的错误**

### 数据竞争表现
```java
public class Demo {
    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();
        Thread t1 = new Thread(counter);
        Thread t2 = new Thread(counter);
        t1.start();
        t2.start();
        t1.join();
        t2.join();
        System.out.println("Final count: " + counter.getCount());
    }
}
class Counter implements Runnable {
    private int count = 0;
    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) {
            count++;
        }
    }
    public int getCount() {
        return count;
    }
}
```

### 数据竞争解决方案

为了解决数据竞争问题，可以使用 `synchronized` 同步机制，确保同一时间只有一个线程可以访问共享资源。以下是修改后的代码：

```java
public class Demo {
    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();
        Thread t1 = new Thread(counter);
        Thread t2 = new Thread(counter);
        t1.start();
        t2.start();
        t1.join();
        t2.join();
        System.out.println("Final count: " + counter.getCount());
    }
}
class Counter implements Runnable {
    private int count = 0;
    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) {
            synchronized (this) { // 使用同步块
                count++;
            }
        }
    }
    public int getCount() {
        return count;
    }
}
```

## 2.`synchronized` 的作用和用法

` synchronized` 是 Java 中用于控制多线程访问共享资源的关键字，主要用于确保线程安全。它通过锁定对象或代码块，确保同一时间只有一个线程可以执行特定的代码段，从而避免数据竞争和线程不安全问题。

### 作用
- `synchronized` 确保同一时间只有一个线程可以访问被锁定的代码块或方法。
- 防止多个线程同时修改共享资源，从而避免数据不一致问题。


### 用法
` synchronized` 可以用于方法或代码块，具体用法如下：

#### 1. 同步方法
- ##### **同步实例方法（锁加到对象上）**：
  
  - 锁定当前实例对象（`this`）。
  - 适用于保护当前对象的共享资源。
  - 如果Demo的实例为demo,同一时刻只能有一个线程执行demo中被 synchronized 修饰的对象方法，如果线程A调用了increment(),线程B不但不能执行demo.increment(),也不能执行demo.getCount()
  - 如果Demo的两个实例为demo1/demo2,线程1执行demo1.increment()同时线程2可以执行demo2.increment()。

```java
public class Demo {
    private int count = 0;
    public synchronized void increment() {
        count++;
    }
    public synchronized int getCount() {
        return count;
    }
    public static void main(String[] args) throws InterruptedException {
        Demo demo = new Demo();
        Thread t1 = new IncrementThread(demo);
        Thread t2 = new IncrementThread(demo);
        t1.start();
        t2.start();
        t1.join();
        t2.join();
        System.out.println("Final count: " + demo.getCount());
    }
}

class IncrementThread extends Thread {
    private Demo demo;
    public IncrementThread(Demo demo) {
        this.demo = demo;
    }
    @Override
    public void run() {
        for (int i = 0; i < 10000; i++) {
            demo.increment();
        }
    }
}
```

- ##### 同步静态方法（锁加到整个类上）锁定当前类的 `Class` 对象。

  - 适用于保护类级别的共享资源。
  - 如果Demo的两个实例为demo1/demo2,线程1执行demo1.increment() 线程2**不可以**执行demo2.increment()。

```java
public class Demo {
    private static int count = 0;
    public static synchronized void increment() {
        count++;
    }
    public static synchronized int getCount() {
        return count;
    }
    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new IncrementThread();
        Thread t2 = new IncrementThread();
        t1.start();
        t2.start();
        t1.join();
        t2.join();
        System.out.println("Final count: " + Demo.getCount());
    }
}
class IncrementThread extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 10000; i++) {
            Demo.increment();
        }
    }
}
```

#### 2. 同步代码块
- **同步实例代码块** ：
  - 锁定当前实例对象（`this`）等价于实例方法前面加synchronized。
  - 适用于保护当前对象的共享资源。

```java
public class Demo {
    private int count = 0;
    public void increment() {
        synchronized (this) { // 锁定当前实例对象
            count++;
        }
    }
    public int getCount() {
        synchronized (this) { // 锁定当前实例对象
            return count;
        }
    }
    public static void main(String[] args) throws InterruptedException {
        Demo demo = new Demo();
        Thread t1 = new IncrementThread(demo);
        Thread t2 = new IncrementThread(demo);
        t1.start();
        t2.start();
        t1.join();
        t2.join();
        System.out.println("Final count: " + demo.getCount());
    }
}
class IncrementThread extends Thread {
    private Demo demo;
    public IncrementThread(Demo demo) {
        this.demo = demo;
    }
    @Override
    public void run() {
        for (int i = 0; i < 10000; i++) {
            demo.increment();
        }
    }
}
```

- **同步静态代码块**：
  - 锁定当前类的 `Class` 对象等价于类方法前面加synchronized。
  - 适用于保护类级别的共享资源。

```java
public class Demo {
    private static int count = 0;
    public void increment() {
        synchronized (Demo.class) { // 锁定当前类的 Class 对象
            count++;
        }
    }
    public int getCount() {
        synchronized (Demo.class) { // 锁定当前类的 Class 对象
            return count;
        }
    }
    public static void main(String[] args) throws InterruptedException {
        Demo demo = new Demo();
        Thread t1 = new IncrementThread(demo);
        Thread t2 = new IncrementThread(demo);
        t1.start();
        t2.start();
        t1.join();
        t2.join();
        System.out.println("Final count: " + demo.getCount());
    }
}

class IncrementThread extends Thread {
    private Demo demo;
    public IncrementThread(Demo demo) {
        this.demo = demo;
    }
    @Override
    public void run() {
        for (int i = 0; i < 10000; i++) {
            demo.increment();
        }
    }
}
```

### 总结
- **同步方法**：适用于保护整个方法中的共享资源。
- **同步代码块**：适用于保护方法中的一部分代码，减少锁的粒度，提高效率。
- **锁定对象**：可以锁定当前实例对象（`this`）或类的 `Class` 对象，根据需要选择合适的锁对象。

通过合理使用 `synchronized`，可以有效解决多线程环境中的数据竞争问题，确保程序的线程安全。

#### 4.几种同步锁的等效：

```java
public class Demo {
	//f1 f2的锁可以认为是等效的，锁加到对象上
	//同一时刻，同一个对象的同步方法只能有一个执行

	}
	public void f2() {

	}
	//f3 f4的锁可以认为是等效的，锁加到对类上

	}
	public static  void f4() {

		}
	}

```

## 3. 集合类的数据竞争问题

ArrayList、LinkedList、HashSet、TreeSet、HashMap 和 TreeMap都不是线程安全的，都无法解决数据竞争问题。

#### List数据竞争的例子：

```java
import java.util.ArrayList;
public class Demo {
	public static void main(String[] args) throws InterruptedException {
		ArrayList<Integer> list = new ArrayList<>();
		// 创建两个线程，同时向 ArrayList 中添加元素
		Thread t1 = new AddThread(list, 10000);
		Thread t2 = new AddThread(list, 10000);	
		t1.start();
		t2.start();	
		t1.join();
		t2.join();	
		// 输出最终的列表大小
		System.out.println("Final list size: " + list.size());
	}
}

class AddThread extends Thread {
	private ArrayList<Integer> list;
	private int count;
	public AddThread(ArrayList<Integer> list, int count) {
		this.list = list;
		this.count = count;
	}	
	@Override
	public void run() {
		for (int i = 0; i < count; i++) {
			list.add(i); // 多线程同时访问和修改 ArrayList
		}
	}

}
```

#### Map数据竞争的例子：

这个例子有时候需要运行多次，才能发生冲突

```java
import java.util.HashMap;
public class Demo {
	public static void main(String[] args) throws InterruptedException {
		HashMap<Integer, String> map = new HashMap<>();
		// 创建多个线程，同时向 HashMap 中插入数据
		Thread[] threads = new Thread[8];
		for (int i = 0; i < threads.length; i++) {
			threads[i] = new Thread(new MapModifier(map, i));
		}
		System.out.println("Thread start! ");
		for (Thread t : threads) {
			t.start();
		}	
		for (Thread t : threads) {
			t.join();
		}
		System.out.println("Final map size: " + map.size());
		for (int i = 0; i < map.keySet().size(); i++) {
			map.get(i);
		}
		System.out.println("Map get ok!");
	}
}

class MapModifier implements Runnable {
	private HashMap<Integer, String> map;
	private int id;
	private int size = 100000;
	public MapModifier(HashMap<Integer, String> map, int id) {
		this.map = map;
		this.id = id;
	}	
	@Override
	public void run() {
		for (int i = 0; i < size; i++) {
			map.put(id * size + i, "Value " + i); // 多线程并发修改 HashMap
		}
	}
}
```

#### 集合类多线程解决方案

`Collections.synchronizedSet`、`Collections.synchronizedList` 和 `Collections.synchronizedMap` 是 Java 提供的工具方法，用于将普通的集合包装成线程安全的集合。这些方法通过在集合的每个操作上添加同步锁来实现线程安全。

类似如下代码：

```java
List<Integer> list = new ArrayList<>();
List<Integer> synchronizedList = Collections.synchronizedList(list);

Set<Integer> set = new HashSet<>();
Set<Integer> synchronizedSet = Collections.synchronizedSet(set);

Map<Integer, String> map = new HashMap<>();
Map<Integer, String> synchronizedMap = Collections.synchronizedMap(map);

```

#### 改造Map数据竞争的例子：

**比较这个例子和前面“Map数据竞争的例子”代码，理解为什么要面向抽象编程，而不是面向具体编程？**

```java
import java.util.Collections;
import java.util.HashMap;
import java.util.Map;

public class Demo {
	public static void main(String[] args) throws InterruptedException {
		Map<Integer, String> map = new HashMap<>();
		//重点
		Map<Integer, String> syncMap = Collections.synchronizedMap(map);
		Thread[] threads = new Thread[8];
		for (int i = 0; i < threads.length; i++) {
			threads[i] = new Thread(new MapModifier(syncMap, i));
		}
		System.out.println("Thread start! ");
		for (Thread t : threads) {
			t.start();
		}
		for (Thread t : threads) {
			t.join();
		}
		System.out.println("Final map size: " + syncMap.size());
		for (int i = 0; i < map.keySet().size(); i++) {
			map.get(i);
		}
		System.out.println("Map get ok!");
	}
}

class MapModifier implements Runnable {
	private Map<Integer, String> map;
	private int id;
	private int size = 100000;    
    //比较这个函数和前面例子中函数定义的不同，理解为什么要面向抽象编程
	public MapModifier(Map<Integer, String> map, int id) {
		this.map = map;
		this.id = id;
	}    
	@Override
	public void run() {
		for (int i = 0; i < size; i++) {
			map.put(id * size + i, "Value " + i); // 多线程并发修改 HashMap
		}
	}
}

```



## 4. **死锁（Deadlock）**

死锁是指两个或多个线程在执行过程中，因争夺资源而陷入无限等待的状态。死锁的产生通常满足以下四个条件：
- **互斥条件**：资源不能同时被多个线程共享。
- **请求与保持条件**：线程已经持有一个资源，又请求另一个资源。
- **不可剥夺条件**：线程持有的资源不能被强制剥夺。
- **循环等待条件**：存在一个等待循环链。

#### 示例代码
```java
public class Demo {
    public static void main(String[] args) {
        Object lock1 = new Object();
        Object lock2 = new Object();
        Thread t1 = new Thread(new Worker(lock1, lock2, "Thread1"));
        Thread t2 = new Thread(new Worker(lock2, lock1, "Thread2"));
        t1.start();
        t2.start();
    }
}

class Worker implements Runnable {
    private final Object firstLock;
    private final Object secondLock;
    private final String name;
    public Worker(Object firstLock, Object secondLock, String name) {
        this.firstLock = firstLock;
        this.secondLock = secondLock;
        this.name = name;
    }
    @Override
    public void run() {
        synchronized (firstLock) {
            System.out.println(name + " acquired first lock");
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            synchronized (secondLock) {
                System.out.println(name + " acquired second lock");
            }
        }
    }
}
```

#### 输出结果
运行上述代码时，两个线程可能会陷入死锁，因为它们分别持有一个锁，同时等待对方释放另一个锁。
