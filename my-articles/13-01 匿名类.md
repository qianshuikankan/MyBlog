### 匿名类的定义
匿名类是一种没有显式名称的类，通常用于实现接口或继承抽象类。匿名类的特点包括：
1. **没有类名**：匿名类没有显式的类名，因此不能通过类名来创建其他实例。
2. **局部性**：匿名类通常定义在方法内部或某个特定的作用域中，因此它的作用范围是局部的。
3. **单例性**：匿名类的实例通常只有一个，除非显式地创建多个实例。
4. **只能实现接口或继承抽象类**：匿名类必须实现一个接口或继承一个抽象类。

### 匿名类的语法
匿名类的语法如下：
```java
new 父类名() {
    // 匿名类的实现
}
```
或者
```java
new 父接口名() {
    // 匿名类的实现
}
```

### 示例代码

#### 示例1：使用匿名类实现`Runnable`接口

`Runnable`接口是一个函数式接口，它只有一个抽象方法`run()`。匿名类可以用来实现`Runnable`接口，从而创建线程。

```java
public class Demo {
    public static void main(String[] args) {
        // 使用匿名类实现Runnable接口
        Runnable myRunnable = new Runnable() {
            @Override
            public void run() {
                System.out.println("Thread is running using anonymous class!");
            }
        };

        // 创建线程并启动
        Thread myThread = new Thread(myRunnable);
        myThread.start();
    }
}
```

#### 示例2：使用匿名类直接在`Thread`构造器中实现
```java
public class Demo {
    public static void main(String[] args) {
        // 使用匿名类直接在Thread构造器中实现Runnable接口
        Thread myThread = new Thread(new Runnable() {
            @Override
            public void run() {
                System.out.println("Thread is running using anonymous class in constructor!");
            }
        });

        // 启动线程
        myThread.start();
    }
}
```

#### 示例3：使用匿名类实现`TimerTask`

`TimerTask`是一个抽象类，它有一个抽象方法`run()`。匿名类可以用来继承`TimerTask`，从而实现定时任务。

```java
import java.util.Timer;
import java.util.TimerTask;

public class Demo {
    public static void main(String[] args) {
        // 创建一个Timer对象
        Timer timer = new Timer();

        // 使用匿名类实现TimerTask
        TimerTask myTimerTask = new TimerTask() {
            @Override
            public void run() {
                System.out.println("TimerTask is running using anonymous class!");
            }
        };

        // 安排任务在1秒后执行，每隔2秒重复执行一次
        timer.scheduleAtFixedRate(myTimerTask, 1000, 2000);
    }
}
```

### 匿名类的优点
1. **简洁性**：匿名类可以在需要的地方直接定义，代码更加简洁。
2. **局部性**：匿名类的作用范围是局部的，不会污染全局命名空间。
3. **灵活性**：匿名类可以快速实现接口或抽象类，适合简单的实现。

### 匿名类的缺点
1. **可读性**：如果匿名类的实现过于复杂，代码的可读性会变差。
2. **重用性**：匿名类不能被重用，每次需要实现相同的功能时，都需要重新定义。
