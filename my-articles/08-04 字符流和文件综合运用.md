## 1 复制一个文件

**注意复制文件一定要使用【字节流】读写，不要使用【字符流】读写**

```java
import java.io.*;

public class Demo {
    public static void main(String[] args) {
        String sourceFilePath = "D:/temp/src.txt";
        String targetFilePath = "D:/temp/target.txt";
        try {
            copyFile(sourceFilePath, targetFilePath);
            System.out.println("文件复制成功！");
        } catch (IOException e) {
            System.err.println("文件复制失败：" + e.getMessage());
        }
    }
    
    public static void copyFile(String sourceFilePath, String targetFilePath) throws IOException {
        File sourceFile = new File(sourceFilePath);
        File targetFile = new File(targetFilePath);    
        if (!sourceFile.exists()) {
            throw new FileNotFoundException("源文件不存在：" + sourceFilePath);
        }    
        //这个地方一定不能使用Reader/Writer,要用 InputStream/OutputStream
        try (FileInputStream fis = new FileInputStream(sourceFile);
             FileOutputStream fos = new FileOutputStream(targetFile)) {  
            byte[] buffer = new byte[1024*1024];
            int length;    
            //标准的复制文件方法
            while ((length = fis.read(buffer)) != -1) {
                fos.write(buffer, 0, length);
            }
        } catch (Exception e) {
            System.err.println(e.getMessage());
        } 
    }
}
```

## 2 把一段文本 或者byte[]写到文件中

- new FileOutputStream(file) 新建以文件 
- new FileOutputStream(file, append=true/false)是否追加内容
- String.getBytes() 字符串转换为byte的方法
- String.getBytes("UTF=8") 强制使用UTF-8编码方式把字符串转换为byte的方法
- 适用于大多数场景（能够一次性载入内存的文件，比如一个照片、一个论文、一个网页、一个小说、一个作业）

```java

import java.io.*;

public class Demo {
	public static void main(String[] args) {
		try {
			String filePath = "D:/temp/example.txt";
			byte[] data = "hellow".getBytes();
			writeBytesToFile(data, filePath, true);
			System.out.println("字节数组已成功写入文件！");
		} catch (IOException e) {
			System.err.println("写入文件时发生错误：" + e.getMessage());
		}
	}

	public static void writeBytesToFile(byte[] data, String filePath, boolean append) throws IOException {
		File file = new File(filePath);
		try (FileOutputStream fos = new FileOutputStream(file, append)) {
			fos.write(data);
		}
	}

}
```

## 3 以byte[]方式读取一个文件，打印出来

**readFileToByteArray 和 readFileToByteArray2 哪个方法更好？**

```java
import java.io.*;

public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";
        try {
            byte[] fileContent = readFileToByteArray(filePath);  
            //注意编码方式,本例子的重点
            String txt=new String(fileContent,"UTF-8");
            System.out.println(txt);
            // 可以根据需要对fileContent进行进一步处理
        } catch (IOException e) {
            System.err.println("读取文件时发生错误：" + e.getMessage());
        }
    }

    //下面两个方法哪个更好？
    public static byte[] readFileToByteArray(String filePath) throws IOException {
        File file = new File(filePath);
        byte[] buffer = new byte[(int) file.length()];
        try (FileInputStream fis = new FileInputStream(file)) {
            fis.read(buffer);
        }
        return buffer;
    }
    
    public static byte[] readFileToByteArray2(String filePath) throws IOException {
        int chunkSize = 1024; // 例如，每次读取 1024 字节
        byte[] buffer = new byte[chunkSize]; // 用于存储每次读取的块
        ByteArrayOutputStream byteArrayOutputStream = new ByteArrayOutputStream();
        try (FileInputStream fileInputStream = new FileInputStream(filePath)) {
            int bytesRead;
            while ((bytesRead = fileInputStream.read(buffer)) != -1) {
                byteArrayOutputStream.write(buffer, 0, bytesRead);
            }
        }
        return byteArrayOutputStream.toByteArray();
    }
}
```

## 4 以char[]方式读取一个文件，使用系统默认编码，打印出来

```java
import java.io.*;
public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";

        try {
            StringBuffer fileContent = readFileToStringBuffer(filePath);
            System.out.println("文件内容已成功读取到StringBuffer中！");
            System.out.println(fileContent.toString());
        } catch (IOException e) {
            System.err.println("读取文件时发生错误：" + e.getMessage());
        }
    }

    public static StringBuffer readFileToStringBuffer(String filePath) throws IOException {
        File file = new File(filePath);
        StringBuffer stringBuffer = new StringBuffer();
        char[] buffer = new char[1024]; 
        
        try (FileReader fileReader = new FileReader(file)) {
            int length;
            while ((length = fileReader.read(buffer)) != -1) {
                stringBuffer.append(buffer, 0, length);
            }
        }
        return stringBuffer;
    }
}
```

## 5 以char[]方式读取一个文件，使用指定(UTF-8)编码，打印出来

**这是比较标准的读取文本文件的方法**

```java
import java.io.*;

public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";
        try {
            StringBuffer fileContent = readFileToStringBuffer(filePath);
            System.out.println("文件内容已成功读取到StringBuffer中！");
            System.out.println(fileContent.toString());
        } catch (IOException e) {
            System.err.println("读取文件时发生错误：" + e.getMessage());
        }
    }

    public static StringBuffer readFileToStringBuffer(String filePath) throws IOException {
        StringBuffer stringBuffer = new StringBuffer();
        char[] buffer = new char[1024]; 
         //注意怎样指定编码方式,本例子的重点
        try (FileInputStream fis = new FileInputStream(filePath);
             InputStreamReader isr = new InputStreamReader(fis, "UTF-8")) {
            int length;
            while ((length = isr.read(buffer)) != -1) {
                stringBuffer.append(buffer, 0, length);
            }
        }
        return stringBuffer;
    }
}
```

**注意：为了增强程序的健壮性，强烈推荐使用指定的编码读取文件，而不要依赖系统的默认编码（因为不同系统默认编码不一样UTF-8/GBK)。**

## 6 每行一个读取文本文件

### 1.正确做法LineNumberReader

注意：逐行读取文本，使用LineNumberReader.readLine()是最标准的方式，不要读取一个整个字符串，然后用String.split("\r\n ")，String.split出错可能性非常大

```java
import java.io.*;

public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";
        try {
            readFileAndPrintWithLineNumbers(filePath);
        } catch (IOException e) {
            System.err.println("读取文件时发生错误：" + e.getMessage());
        }
    }
    public static void readFileAndPrintWithLineNumbers(String filePath) throws IOException {
        try (FileInputStream fis = new FileInputStream(filePath);
             InputStreamReader isr = new InputStreamReader(fis, "UTF-8");
             LineNumberReader lnr = new LineNumberReader(isr)) {
            String line;
            while ((line = lnr.readLine()) != null) {
                System.out.println(lnr.getLineNumber() + ": " + line);
            }
        }
    }
}
```

### 2.错误做法：

```java
import java.io.*;
public class Demo {
    public static void main(String[] args) {
        String filePath = "D:/temp/example.txt";
        try {
            byte[] fileContent = readFileToByteArray(filePath);
            String content = new String(fileContent, "UTF-8");
            //这种方法并不好，不同操作系统每行分隔符不一样，
            //Windows： \r\n  Linux： \n  macOS：\n
            String[] lines = content.split("\r\n");
            for (int i = 0; i < lines.length; i++) {
                System.out.println((i + 1) + ": " + lines[i]);
            }
        } catch (IOException e) {
            System.err.println("读取文件时发生错误：" + e.getMessage());
        }
    }
    public static byte[] readFileToByteArray(String filePath) throws IOException {
        File file = new File(filePath);
        byte[] buffer = new byte[(int) file.length()];
        try (FileInputStream fis = new FileInputStream(file)) {
            fis.read(buffer);
        }
        return buffer;
    }
}
```

## 7 一个综合运用的例子：

学生排名程序：example.txt中每行一个存放了学生信息，格式如下：

```
张三,85
李四,92
王五,78
赵六,88
孙七,95
```

写一个程序，根据上述文件内容，读取出每个学生的成绩，然后按总成绩由高到低排序

```java
import java.io.*;
import java.util.*;

// 1. 构造一个Student类，包含name,score两个属性，并实现Comparable接口
class Student implements Comparable<Student> {
    String name;
    int score;
    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }    
    @Override
    public String toString() {
        return "学生姓名: " + name + ", 总成绩: " + score;
    }    
    // 实现Comparable接口的compareTo方法，按总成绩降序排序
    @Override
    public int compareTo(Student other) {
        return Integer.compare(other.score, this.score); // 降序排序
    }
}

public class Demo {
    public static void main(String[] args) {
        try {
            // 2. 使用LineNumberReader读取文件并解析为Student对象列表
            List<Student> students = readStudentsFromFile("D:/temp/example.txt");            
            // 3. 对学生对象按总成绩排序（利用Student类实现的Comparable接口）
            Collections.sort(students);    
            // 4. 打印排序以后的学生信息
            System.out.println("排序后的学生信息：");
            for (Student student : students) {
                System.out.println(student);
            }
        } catch (Exception e) {
            System.out.println("读取文件时发生错误：" + e.getMessage());
        }
    }    
    // 2. 读取文件并解析为Student对象列表的方法
    public static List<Student> readStudentsFromFile(String filePath) throws IOException, IllegalArgumentException {
        List<Student> students = new ArrayList<>();
        try (FileInputStream fis = new FileInputStream(filePath);
             InputStreamReader isr = new InputStreamReader(fis, "UTF-8"); // 指定以UTF-8编码读取
             LineNumberReader reader = new LineNumberReader(isr)) {
            String line;
            while ((line = reader.readLine()) != null) {
                // 按逗号分割字符串，获取学生姓名和总成绩
                String[] parts = line.split(",");
                if (parts.length != 2) {
                    throw new IllegalArgumentException("无效的输入格式: " + line);
                }
                String name = parts[0].trim();
                int score = Integer.parseInt(parts[1].trim());
                students.add(new Student(name, score));
            }
        }
        return students;
    }
}
```
