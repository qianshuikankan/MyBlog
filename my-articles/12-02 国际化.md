Java 的国际化（Internationalization，简称 i18n）是指设计软件以便它可以适应不同的语言和区域，而无需进行代码修改。国际化的目标是使软件能够支持多种语言和文化环境，从而在全球范围内使用。Java 提供了丰富的国际化支持，主要通过以下几种机制来实现：

### 示例 1：使用 `ResourceBundle` 和资源文件

#### 资源文件
创建两个资源文件，分别用于英语和中文：
- `messages_en.properties`（英语）
  
  ```
  greeting=Hello
  farewell=Goodbye
  ```
```
  
- `messages_zh_CN.properties`（中文）
```
  greeting=你好
  farewell=再见



#### 主程序 `Demo.java`


```java
import java.util.Locale;
import java.util.ResourceBundle;

public class Demo {
    public static void main(String[] args) {
        // 设置用户的语言和区域
        Locale locale = new Locale("zh", "CN"); // 中文（中国）

        // 加载资源文件
        ResourceBundle bundle = ResourceBundle.getBundle("messages", locale);

        // 获取本地化的字符串
        String greeting = bundle.getString("greeting");
        String farewell = bundle.getString("farewell");

        System.out.println(greeting); // 输出：你好
        System.out.println(farewell); // 输出：再见
    }
}
```

### 示例 2：使用 `Locale` 和 `ResourceBundle` 动态切换语言

#### 资源文件
使用与示例 1 相同的资源文件。

#### 主程序 `Demo.java`
```java
import java.util.Locale;
import java.util.ResourceBundle;
import java.util.Scanner;

public class Demo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("请输入语言代码（如 'en' 或 'zh_CN'）：");
        String languageCode = scanner.nextLine();

        Locale locale;
        if (languageCode.contains("_")) {
            String[] parts = languageCode.split("_");
            locale = new Locale(parts[0], parts[1]);
        } else {
            locale = new Locale(languageCode);
        }

        ResourceBundle bundle = ResourceBundle.getBundle("messages", locale);

        String greeting = bundle.getString("greeting");
        String farewell = bundle.getString("farewell");

        System.out.println(greeting);
        System.out.println(farewell);
    }
}
```

### 示例 3：格式化数字和日期

#### 主程序 `Demo.java`
```java
import java.text.NumberFormat;
import java.text.SimpleDateFormat;
import java.util.Locale;

public class Demo {
    public static void main(String[] args) {
        Locale locale = new Locale("zh", "CN");

        // 格式化数字
        NumberFormat numberFormat = NumberFormat.getInstance(locale);
        System.out.println("格式化数字: " + numberFormat.format(1234567.89));

        // 格式化日期
        SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss", locale);
        System.out.println("格式化日期: " + dateFormat.format(new java.util.Date()));
    }
}
```

### 示例 4：使用 `MessageFormat` 格式化消息

#### 资源文件
使用与示例 1 相同的资源文件。

#### 主程序 `Demo.java`
```java
import java.text.MessageFormat;
import java.util.Locale;
import java.util.ResourceBundle;

public class Demo {
    public static void main(String[] args) {
        Locale locale = new Locale("zh", "CN");

        ResourceBundle bundle = ResourceBundle.getBundle("messages", locale);

        String messagePattern = bundle.getString("message");
        String formattedMessage = MessageFormat.format(messagePattern, "Alice", 30);

        System.out.println(formattedMessage);
    }
}
```

#### 资源文件 `messages_zh_CN.properties`
```
message={0}，你的年龄是{1}岁。
```

### 示例 5：动态切换语言和格式化

#### 资源文件
使用与示例 1 相同的资源文件。

#### 主程序 `Demo.java`
```java
import java.text.MessageFormat;
import java.util.Locale;
import java.util.ResourceBundle;
import java.util.Scanner;

public class Demo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("请输入语言代码（如 'en' 或 'zh_CN'）：");
        String languageCode = scanner.nextLine();

        Locale locale;
        if (languageCode.contains("_")) {
            String[] parts = languageCode.split("_");
            locale = new Locale(parts[0], parts[1]);
        } else {
            locale = new Locale(languageCode);
        }

        ResourceBundle bundle = ResourceBundle.getBundle("messages", locale);

        String greeting = bundle.getString("greeting");
        String farewell = bundle.getString("farewell");
        String messagePattern = bundle.getString("message");

        String formattedMessage = MessageFormat.format(messagePattern, "Alice", 30);

        System.out.println(greeting);
        System.out.println(formattedMessage);
        System.out.println(farewell);
    }
}
```

#### 资源文件 `messages_zh_CN.properties`
```
greeting=你好
farewell=再见
message={0}，你的年龄是{1}岁。
```
