Java中的函数式编程是Java 8引入的一个重要特性，它允许你以更简洁、更灵活的方式编写代码。函数式编程的核心是函数可以作为参数传递、作为返回值返回，或者存储在变量中。Java通过引入Lambda表达式和一系列函数式接口来支持函数式编程。

## 1.函数式编程
Java 8引入了几个重要的函数式接口，这些接口定义了常见的函数式操作。以下是一些常用的函数式接口及其方法和作用：

1. **`Consumer<T>`**
   - **方法**：`void accept(T t)`
   - **作用**：对输入参数执行操作，无返回值。
   
2. **`Supplier<T>`**
   - **方法**：`T get()`
   - **作用**：提供一个结果，无输入参数。
   
3. **`Function<T, R>`**
   - **方法**：`R apply(T t)`
   - **作用**：接受一个输入参数，返回一个结果。
   
4. **`Predicate<T>`**
   - **方法**：`boolean test(T t)`
   - **作用**：对输入参数进行布尔测试，返回一个布尔值。
   
5. **`BiFunction<T, U, R>`**
   - **方法**：`R apply(T t, U u)`
   - **作用**：接受两个输入参数，返回一个结果。

## 2. Lambda表达式

Lambda表达式是Java 8引入的一个非常强大的特性，它允许你以更简洁的方式实现函数式接口（即只有一个抽象方法的接口）。Lambda基本语法如下：

```java
(参数列表) -> {
    // 方法体
}
```

- **参数列表**：可以有零个或多个参数，参数类型可以省略（类型推断）。
- **箭头符号**：`->`，表示参数和方法体之间的分隔。
- **方法体**：可以是单条语句或代码块。如果方法体只有一条语句，可以省略大括号 `{}` 和 `return` 关键字。

### 函数式编程/Lambda表达式示例代码

#### 示例1：使用`Consumer<T>`遍历集合

```java
import java.util.Arrays;
import java.util.List;

public class Demo {
    public static void main(String[] args) {
        // 创建一个List
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");

        // 使用Consumer接口遍历并打印每个元素
        names.forEach(new Consumer<String>() {
            @Override
            public void accept(String name) {
                System.out.println(name);
            }
        });
    }
}
```

#### 示例2：使用`Supplier<T>`生成随机数
```java
import java.util.Random;
import java.util.function.Supplier;

public class Demo {
    public static void main(String[] args) {
        // 创建一个Supplier接口实例
        Supplier<Integer> randomSupplier = new Supplier<Integer>() {
            @Override
            public Integer get() {
                return new Random().nextInt(100);
            }
        };

        // 使用Supplier生成随机数
        System.out.println("Random number: " + randomSupplier.get());
    }
}
```

#### 示例3：使用`Function<T, R>`将字符串转换为大写
```java
import java.util.Arrays;
import java.util.List;
import java.util.function.Function;

public class Demo {
    public static void main(String[] args) {
        // 创建一个List
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");

        // 使用Function接口将字符串转换为大写
        Function<String, String> upperCaseFunction = new Function<String, String>() {
            @Override
            public String apply(String name) {
                return name.toUpperCase();
            }
        };

        // 使用Function接口处理每个元素
        for (String name : names) {
            System.out.println(upperCaseFunction.apply(name));
        }
    }
}
```

#### 示例4：使用`Predicate<T>`过滤集合
```java
import java.util.Arrays;
import java.util.List;
import java.util.function.Predicate;

public class Demo {
    public static void main(String[] args) {
        // 创建一个List
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");

        // 使用Predicate接口过滤长度大于3的字符串
        Predicate<String> lengthPredicate = new Predicate<String>() {
            @Override
            public boolean test(String name) {
                return name.length() > 3;
            }
        };

        // 使用Predicate接口过滤集合
        for (String name : names) {
            if (lengthPredicate.test(name)) {
                System.out.println(name);
            }
        }
    }
}
```

#### 示例5：使用`BiFunction<T, U, R>`拼接两个字符串
```java
import java.util.function.BiFunction;

public class Demo {
    public static void main(String[] args) {
        // 创建一个BiFunction接口实例
        BiFunction<String, String, String> concatFunction = new BiFunction<String, String, String>() {
            @Override
            public String apply(String s1, String s2) {
                return s1 + " " + s2;
            }
        };

        // 使用BiFunction接口拼接两个字符串
        System.out.println("Concatenated string: " + concatFunction.apply("Hello", "World"));
    }
}
```



## 2. 集合类对函数式编程的支持

在 Java 中，`Collection` 接口提供了 `forEach` 和 `removeIf` 方法，它们是集合类中非常有用的工具，可以用来遍历集合和根据条件移除元素。

### 1. `Collection`中`forEach` 方法

#### 方法定义
```java
default void forEach(Consumer<? super E> action)
```

- **参数**：
  - `Consumer<? super E> action`：一个 `Consumer` 函数式接口的实现，用于接收集合中的每个元素并执行操作。
- **作用**：
  - 遍历集合中的每个元素，并对每个元素执行 `action` 指定的操作。

#### 示例代码  操作List
```java
import java.util.Arrays;
import java.util.List;
import java.util.function.Consumer;

public class Demo {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("apple", "banana", "cherry", "date");

        // 使用匿名类实现 Consumer 接口
        list.forEach(new Consumer<String>() {
            @Override
            public void accept(String item) {
                System.out.println("Processing item: " + item);
            }
        });

        // 使用 forEach 遍历集合
        list.forEach(item -> {
            System.out.println("Processing item: " + item);
        });

    }
}
```

### 2. `Map` 的 `forEach` 方法定义

#### 方法定义
```java
default void forEach(BiConsumer<? super K, ? super V> action)
```

- **参数**：
  - `BiConsumer<? super K, ? super V> action`：一个 `BiConsumer` 函数式接口的实现，用于接收两个参数（键和值）并执行操作。
- **作用**：
  - 遍历 `Map` 中的每个键值对，并对每个键值对执行 `action` 指定的操作。

#### 示例代码  操作Map

```java
import java.util.HashMap;
import java.util.Map;
import java.util.function.Consumer;

public class Demo {
    public static void main(String[] args) {
        Map<String, Integer> map = new HashMap<>();
        map.put("apple", 1);
        map.put("banana", 2);
        map.put("cherry", 3);

        // 使用匿名类实现 Consumer 接口
        map.entrySet().forEach(new Consumer<Map.Entry<String, Integer>>() {
            @Override
            public void accept(Map.Entry<String, Integer> entry) {
                System.out.println("Key: " + entry.getKey() + ", Value: " + entry.getValue());
            }
        });

        // 使用 entrySet() 和 forEach 遍历 Map
        map.entrySet().forEach(entry -> {
            System.out.println("Key: " + entry.getKey() + ", Value: " + entry.getValue());
        });
    
         // 使用Lambda表达式遍历Map的键值对
        System.out.println("遍历Map的键值对：");
        map.forEach((key, value) -> System.out.println(key + ": " + value));

    }

}
```



### 3. `Collection`中`removeIf` 方法

#### 方法定义
```java
default boolean removeIf(Predicate<? super E> filter)
```

- **参数**：
  - `Predicate<? super E> filter`：一个 `Predicate` 函数式接口的实现，用于接收集合中的每个元素并返回一个布尔值。
- **作用**：
  - 遍历集合中的每个元素，如果 `filter.test(element)` 返回 `true`，则移除该元素。
- **返回值**：
  - `boolean`：如果集合中有元素被移除，则返回 `true`；否则返回 `false`。

**注意：Map没有`removeIf` 方法**

#### 示例代码

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.function.Predicate;

public class Demo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>(Arrays.asList("apple", "banana", "cherry", "date"));

        // 使用匿名类实现 Predicate 接口
        list.removeIf(new Predicate<String>() {
            @Override
            public boolean test(String item) {
                return item.length() > 5;
            }
        });
        System.out.println("After removeIf with anonymous class: " + list);
        
        // 使用 removeIf 移除长度大于 5 的字符串
        list.removeIf(item -> item.length() > 4);
        System.out.println("After removeIf with lambda: " + list);
    }
}
```

## 3. 其他例子

### 示例：排序

Lambda表达式可以用于对集合进行排序，例如对`List`进行排序。

```java
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;

public class Demo {
    public static void main(String[] args) {
        // 创建一个List
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");

        // 使用Lambda表达式对List进行自然排序
        System.out.println("自然排序：");
        names.sort((s1, s2) -> s1.compareTo(s2));
        names.forEach(System.out::println);

        // 使用Lambda表达式对List进行长度排序
        System.out.println("按长度排序：");
        names.sort((s1, s2) -> Integer.compare(s1.length(), s2.length()));
        names.forEach(System.out::println);
    }
}
```

### 示例：使用方法引用

方法引用是Lambda表达式的一种简化形式，它可以直接引用已有的方法。方法引用可以进一步简化代码。

```java
import java.util.Arrays;
import java.util.List;

public class Demo {
    public static void main(String[] args) {
        // 创建一个List
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");

        // 使用方法引用对List进行自然排序
        System.out.println("自然排序（方法引用）：");
        names.sort(String::compareTo);
        names.forEach(System.out::println);

        // 使用方法引用对List进行长度排序
        System.out.println("按长度排序（方法引用）：");
        names.sort(Comparator.comparingInt(String::length));
        names.forEach(System.out::println);
    }
}
```
