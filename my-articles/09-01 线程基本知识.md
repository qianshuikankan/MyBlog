## 1. 什么是线程

线程（Thread）是操作系统能够进行调度的最小单位。一个进程包含很多线程。线程是程序执行的最小单位，允许程序在单个进程中同时执行多个任务。线程之间共享进程的资源，如内存空间和文件句柄。每个同学电脑上都有几千个线程在运行。

## 2. 线程的作用

线程的主要作用是实现并发编程，提高程序的执行效率和响应速度。以下是线程的几个主要作用：

### 提高程序的执行效率

通过多线程，程序可以同时执行多个任务，充分利用多核处理器的计算能力，从而提高程序的执行效率。

### 提高程序的响应速度

多线程可以提高程序的响应速度，特别是在处理 I/O 操作时。例如，一个线程可以处理用户输入，另一个线程可以处理后台计算。

### 实现多任务处理

线程可以用于实现多任务处理，例如在一个程序中同时执行多个不同的任务。

## 3. 实现线程的两种方式-

### 1：通过继承 `Thread` 类实现线程

```java
// Demo.java
class MyThread extends Thread {
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println("线程 " + Thread.currentThread().getName() + " 输出: " + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
public class Demo {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        //注意是start(),不是run()
        t1.start();
        System.out.println("主程序已经执行结束");
    }
}
```

###  2：通过实现 `Runnable` 接口实现线程

```java
// Demo.java
class MyRunnable implements Runnable {
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println("线程 " + Thread.currentThread().getName() + " 输出: " + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}

public class Demo {
    public static void main(String[] args) {
        Thread t1 = new Thread(new MyRunnable());
        //注意是start(),不是run()        
        t1.start();
        System.out.println("主程序已经执行结束");
    }
}
```
### 说明
- **继承 `Thread` 类**：通过创建 `MyThread` 类继承 `Thread` 类，并重写 `run` 方法来定义线程的行为。
- **实现 `Runnable` 接口**：通过创建 `MyRunnable` 类实现 `Runnable` 接口，并重写 `run` 方法来定义线程的行为。然后通过 `Thread` 类的构造函数将 `Runnable` 对象传递给线程。
- **注意**：启动线程要调用start()，而不是run()

## 4. 线程中的sleep

`Thread.sleep()` 是 Java 中用于让当前线程暂停执行的方法。它是一个静态方法，属于 `Thread` 类。以下是它的简单介绍：

**功能**

- **暂停线程**：使当前线程暂停执行指定的时间。
- **不释放锁**：线程在睡眠期间仍然持有它已经获取的锁。
- **减少 CPU 占用**：线程在睡眠期间不会占用 CPU 资源。
- 线程在调用 `Thread.sleep()` 后会进入 **TIMED_WAITING** 状态（如果指定了时间）或 **WAITING** 状态（如果没有时间限制）。

`Thread.sleep()` 有两种重载形式：

1. `public static void sleep(long millis)`：暂停线程指定的毫秒数。
2. `public static void sleep(long millis, int nanos)`：暂停线程指定的毫秒数和纳秒数（`nanos` 范围是 0 到 999999）。

**使用示例**

```java
public class Demo {
    public static void main(String[] args) {
        System.out.println("Thread is starting...");
        try {
            Thread.sleep(2000); // 暂停线程2秒
        } catch (InterruptedException e) {
            System.out.println("Thread was interrupted!");
        }
        System.out.println("Thread is awake!");
    }
}
```

## 5 线程中 `setDaemon` 的作用

- `setDaemon` 方法用于将线程设置为守护线程。守护线程是一种特殊的线程，它在后台运行，主要用于为其他线程提供服务。
- 通过调用 `setDaemon(true)` 将线程设置为守护线程。
- 所有非守护线程都终止后，程序会自动退出，不会等待守护线程完成。

### 示例程序：使用 `setDaemon` 设置守护线程

```java
// Demo.java
class MyThread extends Thread {
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println("线程 " + Thread.currentThread().getName() + " 输出: " + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}

public class Demo {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        //重点：修改如下参数的true/false,看运行结果有什么不同
        t1.setDaemon(true); 
        t1.start();
        System.out.println("主程序已经执行结束");
    }
}
```



## 6. **`join()` 的作用**

- 当主线程调用某个线程的 `join()` 方法时，主线程会被阻塞，直到被调用 `join()` 的线程执行完成。
- 这确保了主线程不会在子线程完成之前继续执行，从而可以安全地使用子线程的执行结果。
  

### 例子1 多线程计算加和

```java
public class Demo {
    public static void main(String[] args) throws InterruptedException {
        int t = 2; // 线程数量        
        long m = 10000000000L; // 加和范围上限
        long[] results = new long[t];
        Thread[] threads = new Thread[t];
        long startTime = System.currentTimeMillis();
        for (int i = 0; i < t; i++) {
            //这里简化了问题，认为m可以被t整除
            long start = i * (m / t) + 1;
            long end = (i + 1) * (m / t);
            threads[i] = new SumThread(start, end, results, i);
            threads[i].start();
        }
        for (Thread thread : threads) {
            thread.join();
        }
        long totalSum = 0;
        for (long result : results) {
            totalSum += result;
        }
        long endTime = System.currentTimeMillis();
        System.out.println(totalSum);
        System.out.println(endTime - startTime);
    }
}

class SumThread extends Thread {
    private long start;
    private long end;
    private long[] results;
    private int index;
    public SumThread(long start, long end, long[] results, int index) {
        this.start = start;
        this.end = end;
        this.results = results;
        this.index = index;
    }
    @Override
    public void run() {
        long sum = 0;
        for (long i = start; i <= end; i++) {
            sum += i;
        }
        results[index] = sum;
    }
}
```

## 7.线程的优先级
### `setPriority(int priority)`

线程优先级是一个整数值，用于表示线程的相对重要性。线程调度器会根据优先级来分配CPU时间，优先级高的线程通常会获得更多的CPU时间，但不保证总是先执行。在 Java 中，可以通过 `setPriority(int priority)` 方法来设置线程的优先级。线程的优先级是一个整数值，范围是 1 到 10，其中 1 表示最低优先级，10 表示最高优先级。默认情况下，线程的优先级是 5。

### `Thread.yield()` 

`Thread.yield()` 是 Java 中的一个静态方法，用于提示线程调度器让出当前线程的执行权，以便其他线程可以运行。它是一个非阻塞方法，不会使线程进入阻塞状态，而是将线程从运行状态（Running）转换为就绪状态（Runnable），等待再次被调度。有如下作用：

   - 当当前线程调用 `Thread.yield()` 时，它会主动让出当前的CPU时间片，给其他线程一个运行的机会。
   - 这有助于避免某些线程长时间占用CPU，从而提高系统的响应性和公平性。
   
   - 在某些情况下，`Thread.yield()` 可能不会立即让出CPU，而是等待调度器的决定。


### 示例代码
```java
public class Demo {
```
